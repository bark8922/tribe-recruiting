# Intake Tool — Quick Guide

## Setup (once)
You already have the Transcriber extension. In **Settings**:
1. Check the **microphone** is green (allow it if red).
2. Scroll to **Enable intake mode** → toggle it **ON**.
3. **Connect Google Drive** → pick your **Tribe** account (not the client) → click through the "Google hasn't verified" warning and allow access.

No API keys needed. Drive must be connected or the doc won't generate — this is the part that breaks most.

## Run an intake call
1. Join the call → pop-up asks **Screening or Intake** → pick **Intake call**.
2. Talk normally. Say the **client name out loud** at some point so it gets picked up.
3. After the call: pick the **hiring manager** (if not listed, paste their LinkedIn URL to create them — needs name, LinkedIn, email). Assign the **sourcer**. Create the job → it lands in the Tribe Dashboard.
4. Click **Create Google Doc** → filled intake guide saves to the Intake Form folder.

## If it breaks
- Settings → **copy logs** → send to Rodrigo (or your task-force group chat).
- **Doc didn't generate:** known bug Rodrigo's fixing (as of Jun 22). The job still creates fine.
- **Hiring manager not found:** paste their LinkedIn URL.

## Good to know
